Visual Studio: 2026, версия 18.0 (18.10.12224.181)
Тестовая программа: bin\x64\Debug\stage1_testapp.exe
Конфигурация: Debug | x64, /Od, /Zi, /utf-8

6. Почему SIZE 11 недостаточно
------------------------------

В готовой лабораторной на Desktop стоят #define SIZE 11 и #define hideSIZE 11.
На этой сборке Windows 11:

- FindNextFileW: 11 байт совпадают с границей — работает;
- FindFirstFileW: 11 байт режут инструкцию mov dword ptr [rsp+28h],0 — нельзя;
- CreateFileW: 11 байт режут mov eax,[rsp+88h] — нельзя.

Следовательно, для CreateFileW нужен N = 13, для FindFirstFileW — N = 9.
На этапе 2 размер патча должен быть параметром класса HookPatch, а не
глобальной константой.

7. Что ещё учесть в HookPatch
-----------------------------

- rel32 = (int32_t)((uintptr_t)hook - ((uintptr_t)target + 5));
  проверить, что значение влезает в signed 32-bit (±2 ГБ).
- Трамплин: N байт оригинала + FF 25 00 00 00 00 + 8 байт адреса
  (target + N). Итого N + 14 байт, а не N + 8.
- Проверить, что в первых N байтах нет RIP-relative инструкций
  (на снятых прологах их нет).
- При ошибке VirtualAlloc/WriteProcessMemory откатывать уже записанный патч.
